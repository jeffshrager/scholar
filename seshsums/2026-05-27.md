## What happened

**Added `--hist` flag to `report.py`:**
- New `report_hist()` function renders a horizontal-bar histogram to the terminal
- One row per paper; bar length (`█`) is proportional to GS citation count
- Papers ranked top→bottom (highest to lowest) by the chosen `--sortby` metric
- Bar width auto-scales to terminal width (capped at 50 chars / half the terminal)
- Citation count is right-aligned in a fixed-width field so titles line up cleanly
- When `--hist` is active, error-check output is suppressed entirely — histogram only
- `--hist` composes with all existing `--sortby` metrics: `frequency`, `recency`,
  `distance`, `centroid`, `longevity`, `latebloomer`, `momentum`

**Added two new data-quality checks to `check_pubdates.py`:**
- *Incomplete scans* (check 1, new): lists papers with `citations_complete = false`, columns GS / Stored / Shortfall / Year / Title, sorted by shortfall desc — these are the highest-priority papers to re-scrape
- *Count mismatches* (check 2, new): lists papers with `citations_complete = true` but `stored ≠ gs_count`; signed delta (`−` = under-stored, `+` = over-stored), sorted by `|delta|` — flags silent scrape failures or GS count drift
- Date inversions moved to check 3 (unchanged logic)
